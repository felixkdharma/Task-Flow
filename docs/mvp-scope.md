1. What Users can do:
 - Register and log in
 - Update their profile
 - Create a workspace
 - Invite workspace members
 - Create projects
 - Manage tasks through a Kanban board
 - Assign tasks and add comments

2. How Many Roles this app has ?
 - Owner: controls workspace and members
 - Manager: manages projects and tasks
 - Member: works on assigned tasks
 - Viewer: read-only access
